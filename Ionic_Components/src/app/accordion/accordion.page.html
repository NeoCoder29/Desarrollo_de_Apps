Accordion

El componente Accordion permite organizar información en diferentes secciones que se pueden abrir y cerrar al hacer clic.

Ejemplo

¿Qué es Ionic?
Ionic es un framework para desarrollar aplicaciones móviles y aplicaciones web utilizando tecnologías como HTML, CSS y Angular.
¿Qué es Angular?
Angular es un framework basado en TypeScript que permite crear aplicaciones web mediante componentes.
¿Para qué sirve Accordion?
Permite mostrar información de forma organizada sin ocupar demasiado espacio en la pantalla.
